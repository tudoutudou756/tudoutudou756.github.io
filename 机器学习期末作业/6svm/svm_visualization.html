观察要点

• 线性核：边界是一条直线，间隔带是两条平行虚线之间的区域

• 换 RBF 核：边界可以弯出任意形状，轻松分开环形/月牙数据

• C 越大越容忍误差小（易过拟合），C 越小间隔越宽（易欠拟合）

• σ 越小边界越「碎」，越大边界越平滑

SVM 原理

最大间隔分类

找到超平面 w·x + b = 0，使两类样本到它的最小距离（间隔）最大：

min ½||w||²　s.t.　yᵢ(w·xᵢ + b) ≥ 1，y ∈ {−1, +1}

间隔宽度 = 2/||w||。落在间隔边界上的样本（yᵢ(w·xᵢ+b)=1）就是支持向量 —— 只有它们决定边界位置，其余样本删掉也不影响模型。

软间隔与松弛变量

数据线性不可分时引入 ξᵢ 允许个别样本越界：

min ½||w||² + C·Σξᵢ　s.t.　yᵢ(w·xᵢ+b) ≥ 1−ξᵢ，ξᵢ ≥ 0

核技巧

把样本映射到高维空间再找线性边界，但计算时只用到核函数 K(xᵢ,xⱼ)=⟨φ(xᵢ),φ(xⱼ)⟩，无需显式计算 φ：

RBF 核：K(x, x′) = exp(−||x − x′||² / (2σ²))

本演示用最小二乘 SVM（LSSVM）求解：解一个线性方程组得到系数 α，决策函数 f(x) = Σ αᵢK(xᵢ,x) + b。
