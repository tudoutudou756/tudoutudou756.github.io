指标公式速查

Accuracy = (TP + TN) / (TP + TN + FP + FN)
Precision = TP / (TP + FP)　　Recall = TPR = TP / (TP + FN)
F1 = 2 × P × R / (P + R)　　FPR = FP / (FP + TN)
AUC：ROC 曲线下面积，等价于「随机取一正一负两个样本，模型给正样本打分更高」的概率

使用说明

• 拖动顶部滑块改变分类阈值，观察混淆矩阵四个格子的数量变化

• 注意 TPR / FPR 的联动：阈值降低 → 更多样本被判为正例 → TP 与 FP 同时增多

• ROC 曲线上当前阈值对应的点会高亮显示；曲线越靠左上角，模型越好

• 点击混淆矩阵的单元格可以查看 TP / FP / FN / TN 的通俗解释
