Logistic 回归原理

Sigmoid 激活

线性输出通过 Sigmoid 函数压缩到 (0,1)，作为样本属于正类的概率估计：

p = σ(z) = 1 / (1 + e−z)，　z = w₁x₁ + w₂x₂ + b

交叉熵损失

对二分类问题，采用负对数似然（交叉熵）作为损失函数：

L = −(1/n) Σ [ yᵢ·ln(pᵢ) + (1−yᵢ)·ln(1−pᵢ) ]

当 pᵢ 与真实标签 yᵢ 接近时损失趋近 0；预测越自信且越错误，惩罚越大。

梯度下降更新

损失对参数的梯度具有简洁形式（预测误差 × 输入）：

∂L/∂w = (1/n) Σ (pᵢ − yᵢ)·xᵢ，　∂L/∂b = (1/n) Σ (pᵢ − yᵢ)
w ← w − η·∂L/∂w，　b ← b − η·∂L/∂b

其中 η 为学习率。决策边界是 p = 0.5 对应的等值线，即 w₁x₁ + w₂x₂ + b = 0 的一条直线。
